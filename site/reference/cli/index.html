    catplat calculate

    Usage: catplat calculate [OPTIONS]

  Run Catplat workflow calculations.

  Obtains results of specified system by first searching the database. If the results do
  not exist, calculate using DFT.

  \b Examples:     catplat calculate --project <myproject> --chemsys Cu

Options:
  -p, --project STRIPPED_STR      Name of project to run. Contains information such as
                                  database_path, incar settings, etc.  [required]
  --view / --no-view              If true, views the structures of the results
  --write-csv TEXT                Write the retrieved results in csv format.
  --write-yaml TEXT               Write the most stable binding energies to a yaml file.
  --unique                        Filters unique entries.
  --bulk-atoms TEXT               A file containing a structure of the bulk atoms, or a
                                  template with formula and crystal structure, in format
                                  template:{crystal structure}:{formula}, e.g.
                                  template:fcc:Ce. When specified, other bulk attributes
                                  should not be specified.
  --e-above-hull TEXT             The energy above hull of the bulk structure as
                                  indicated on Materials Project. Comparator strings
                                  with ">", "<", ">=", and "<=" (see examples) are
                                  required, as it is unlikely to find an exact match for
                                  the energy above hull.
  --bulk-formula TEXT             The bulk formula as indicated on Materials Project.
                                  Use in combination with chemsys to further narrow down
                                  the search.
  --chemsys TEXT                  The chemical system of the bulk structure as a string
                                  of a list of elements sorted alphabetically and joined
                                  by dashes, by convention for use in database keys.
  --spacegroup INTEGER            The spacegroup number of the bulk structure as
                                  indicated on Materials Project.
  --mpid TEXT                     The Materials Project id of the bulk atoms.
  --max-atoms INTEGER             Limits the number of atoms in the bulk.
  --dopant-symbol TEXT            The symbol of the dopant element to be used in doping
                                  calculations.
  --host-symbol TEXT              The symbol of the host element to be replaced in
                                  doping calculations.
  --max-doped-structures INTEGER  The maximum number of doped structures to generate per
                                  bulk structure.
  --doping-concentration FLOAT    The concentration of the dopant in doping calculations
                                  (between 0 and 1).
  --bulk-supercell-size INTEGER...
                                  Size of supercell to be created in terms of number of
                                  unit cell repeats of the bulk.
  --bulk-tag TEXT                 Tag to identify user bulks. Can only be specified if
                                  bulk_atoms is provided.
  --primitive-standard BOOLEAN    Converts the bulk to primitive standard format.
  --select-best-by-chemsys BOOLEAN
                                  Selects the best bulk for each chemsys based on set
                                  rules.
  --exclude-families COMMA_DELIMITED_STRING
                                  Element families to exclude. Valid families are:
                                  ['ALKALI_METALS', 'ALKALINE_EARTH_METALS',
                                  'TRANSITION_METALS', 'POST_TRANSITION_METALS',
                                  'METALLOIDS', 'REACTIVE_NONMETALS', 'NOBLE_GASES',
                                  'LANTHANOIDS', 'ACTINOIDS', 'SUPERHEAVY']
  --exclude-families-exempted-elements COMMA_DELIMITED_STRING
                                  Elements to exempt from exclude families group.
  --num-sites TEXT                The number of sites of the bulk structure as indicated
                                  on Materials Project. Comparator strings with ">",
                                  "<", ">=", and "<=" (see examples) are preferred here.
  --num-elements TEXT             The number of elements of the bulk structure as
                                  indicated on Materials Project. Comparator strings
                                  with ">", "<", ">=", and "<=" (see examples) are
                                  preferred here.
  --density TEXT                  Density of the structure as indicated on Materials
                                  Project.Comparator strings with ">", "<", ">=", and
                                  "<=" (see examples) are required, as it is unlikely to
                                  find an exact match for the density.
  --band-gap TEXT                 Band gap of the structure as indicated on Materials
                                  Project.Comparator strings with ">", "<", ">=", and
                                  "<=" (see examples) are required, as it is unlikely to
                                  find an exact match for the band gap.
  --theoretical BOOLEAN           Whether structure is theoretical or experimentally
                                  observed.
  --exclude-elements COMMA_DELIMITED_STRING
                                  List of elements to exclude
  --elements COMMA_DELIMITED_STRING
                                  Bulk must contain all of the elements specified here.
  --slab-atoms TEXT               Path to a custom slab structure.
  --termination TEXT              Termination of the slab. Determined by the surface
                                  atoms of the slab. For example, "Ag-Cu" to specify
                                  that the surface has Ag and Cu atoms.
  --miller-index INTEGER...       Miller index of slab to be created.
  --unitcell-size INTEGER...      Number of repeats of the unit cell in x and y
                                  directions.
  --conventional BOOLEAN          Toggle for creation of conventional slabs.
  --num-fixed-layers INTEGER      Number of layers to be fixed.
  --num-layers INTEGER            Number of layers of the slab.
  --vacuum TEXT                   Amount of vacuum to add on each side of the slab. Only
                                  greater than is allowed e.g. ">10"
  --x-length TEXT                 Length of slab in x direction. Only greater than is
                                  allowed e.g. ">10
  --y-length TEXT                 Length of slab in y direction. Only greater than is
                                  allowed e.g. ">10
  --slab-thickness TEXT           Thickness of slab. Only greater than is allowed e.g.
                                  ">10
  --slab-fixed-thickness TEXT     Fixed atoms cutoff in Angstroms. Only greater than is
                                  allowed e.g. ">10"
  --max-terminations INTEGER      Limits the number of slab terminations generated.
  --min-relative-density FLOAT    Minimum relative density of slab.
  --min-symmetry-operations INTEGER
                                  Minimum number of symmetry operations.
  --single-atom-alloy TEXT        Single atom alloy to be added to the slab.
  --overlayer TEXT                Replaces top layer atoms with overlayer atoms.
  --preserve-stoichiometry BOOLEAN
                                  Preserves the stoichiometry of the bulk.
  --slab-tag TEXT                 Tag to identify user slab.
  --binding-specs TEXT            Specify multiple binding specifications for
                                  coadsorption.
  --max-complexes INTEGER         Impose a limit on number of complexes to generate.
  --run-vibration BOOLEAN         Whether to run vibration calculations. If False, no
                                  vibration calculations will be run.
  --ml-preoptimization, --ml-preopt
                                  Flag to run preoptimization with MLPotential. Will
                                  default to True if --ml-potential-hash is specified.
  --ml-potential-hash TEXT        Hash of the MLPotential to be used for
                                  preoptimization.
  --mag-preoptimization, --mag-preopt / --no-mag-preoptimization, --no-mag-preopt
                                  Flag to run magnetic enumeration preoptimization to
                                  find the magnetic ground state.
  --skip-materials-project        Flag to skip querying Materials Project.
  --parallel-workflows / --no-parallel-workflows
                                  Toggle for running workflows in parallel. Should be
                                  True for most cases.
  --parallel-tasks / --no-parallel-tasks
                                  Toggle for running tasks in parallel. Should be True
                                  for most cases.
  --temperature FLOAT
  --pressure FLOAT
  -n, --num-nodes INTEGER         Number of nodes to assign for each num-job-run-slots.
  --num-cores INTEGER             Number of cores to assign for each job. If not
                                  specified, will default to the number of cores on the
                                  specified server.
  --num-gpus INTEGER              Number of GPUs to assign for each job. If not
                                  specified, will default to the number of GPUs on the
                                  specified server.
  -N, --num-job-run-slots INTEGER
                                  Number of jobs to run in parallel.
  --server TEXT                   Name of server to run the job on. Will try to
                                  determine this automatically if unspecified.
  --write-db / --no-write-db      If true, writes calculations of current session to
                                  {session_id}.db
  --help                          Show this message and exit.

    catplat extract

    Usage: catplat extract [OPTIONS]

  Extract calculation information from folders.

  Either update the corresponding relaxed entries in the database or store them anew. \b
  Examples:     catplat extract  -p projectname -f '/path/to/job1' -f '/path/to/job2'
  --id unrelaxedid1 --id unrelaxedid2         --parallel --np 2

      catplat extract  -p projectname -f '/path/to/lot_of_jobs/id*' --overwrite --np -1

Options:
  -p, --project STRIPPED_STR      Name of the project. Stored with each entry in the
                                  database.  [required]
  --db-path STRIPPED_STR          Path to the database file. Defaults to the configured
                                  CatPlat database path if not provided.
  -f, --folder TEXT               The path of the folder(s) from which to extract the
                                  caulation data from.Must be provided under quotes,
                                  e.g. -f "some/path"  [required]
  --id INTEGER                    Database id of the unrelaxed entry whose corresponding
                                  relaxed entry is to be edited.
  --overwrite / --no-overwrite    Toggle to overwrite the existing data section, if one
                                  is found
  --np INTEGER                    Number of parallel threads. Use np=-1 to utilize the
                                  maximum number of available threads
  --suppress-errors / --no-supress-errors
                                  Toggle to silently skip the undesired, normally error-
                                  raising cases
  --chunksize INTEGER             the chunksize option of multiprocessing.Pool.starmap
  --help                          Show this message and exit.

    catplat retrieve

    Usage: catplat retrieve [OPTIONS]

  Queries the database of a project.

  Obtains results of specified system by searching the database only.

  \b Examples:     catplat retrieve --project <myproject> --chemsys Cu

Options:
  --num-procs INTEGER             Number of processes to use for command.
  --write-csv TEXT                Write the retrieved results in csv format.
  --write-yaml TEXT               Write the most stable binding energies to a yaml file.
  --unique                        Filters unique entries.
  --view / --no-view              If true, views the structures of the results
  --spacegroup STR|INT            Spacegroup number of bulk as indicated on Materials
                                  Project.
  --e-above-hull STR|FLOAT        Energy above hull of the bulk structure as indicated
                                  on Materials Project. (eV/atom)
  --bulk-formula TEXT             Formula of the bulk structure as indicated on
                                  Materials Project.
  --chemsys TEXT                  Chemical species of the bulk. Multiple elements should
                                  be separated by dashes.
  --mpid TEXT                     Materials Project ID of bulk structure.
  --bulk-provenance TEXT          String for the origin of bulk atoms.
  --bulk-atoms TEXT               Name of bulk file in user bulk directory. When bulk is
                                  specified, other bulk attributes such as e_above_hull
                                  should not be specified. (except bulk_tag)
  --bulk-supercell-size INT|STR...
                                  Size of bulk structure in terms of number of unit cell
                                  repeats.
  --doping-concentration STR|FLOAT
                                  Doping concentration of the bulk structure. (fraction
                                  of dopant atoms)
  --dopant-symbol TEXT            Chemical symbol of the dopant atom in the bulk
                                  structure.
  --host-symbol TEXT              Chemical symbol of the host atom in the bulk
                                  structure.
  --bulk-tag TEXT                 Tag to identify user bulks.
  --termination TEXT              Slab termination, defined as the composition of the
                                  surface layer.
  --miller-index INT|STR...       Miller index of slab.
  --unitcell-size INT|STR...      Size of slab to be created in terms of number of unit
                                  cell repeats.
  --overlayer TEXT                If specified, replaces top layer atoms with overlayer
                                  atoms.
  --num-layers STR|INT            Number of layers in the slab.
  --num-fixed-layers STR|INT      Number of fixed layers.
  --slab-fixed-thickness STR|FLOAT
                                  Thickness of the fixed layers. (Å)
  --vacuum STR|INT|FLOAT          Vacuum thickness added on each side of the slab. Total
                                  vacuum = vacuum x 2. (Å)
  --conventional BOOLEAN          Whether the slab is in conventional cell.
  --x-length STR|FLOAT            Length of the slab in the x direction. (Å)
  --y-length STR|FLOAT            Length of the slab in the y direction. (Å)
  --slab-thickness STR|FLOAT      Thickness of the slab. (Å)
  --slab-chemsys TEXT             Species of the slab, sorted alphabetically and
                                  separated by dashes.
  --slab-formula TEXT             Formula of the slab.
  --slab-acn STR|FLOAT            Average Coordination Number of the slab surface atoms.
  --slab-provenance TEXT          String for the origin of slab atoms.
  --single-atom-alloy TEXT        Single atom alloy.
  --slab-atoms TEXT               Name of slab file in user slab directory. When slab is
                                  specified, other bulk and slab attributes should not
                                  be specified. (except slab_tag)
  --slab-tag TEXT                 Tag to identify user slabs.
  --task-type TEXT                Type of workflow.
  --unrelaxed-id STR|INT          Unrelaxed database id.
  --relaxed BOOLEAN               Boolean specifying if structures are relaxed.
  --errored BOOLEAN               Include errored entries.
  --ignored BOOLEAN               Include ignored entries.
  --version TEXT                  Version of the database entry.
  --session-id TEXT               Session id of the database entry.
  --job-id TEXT                   Job id of the database entry, for CatPlat Cloud API.
  --date STR|FLOAT                Date of the database entry.
  --ml-preoptimization BOOLEAN    Boolean specifying if structures are ML preoptimized.
  --ml-preoptimization-id STR|INT
                                  ID of the ML preoptimized structure.
  --mag-preoptimization BOOLEAN   Boolean specifying if structures are magnetism
                                  preoptimized.
  --mag-preoptimization-id STR|INT
                                  ID of the magnetism preoptimized structure.
  --project-name, --project TEXT  Name of the project this entry belongs to.
  --parent-ids LITERAL_EVAL       IDs of the parents of the workflow.
  --id STR|INT
  --adsorbate-atoms COMMA_DELIMITED_STRING
                                  Name of adsorbate.Accepted inputs:(1) "path/to/X.xyz"
                                  (2) "X" if X.* in user/catplat adsorbate directory (3)
                                  "X" if X in ase.collections.g2 (4) "X" if X is a
                                  Chemical Symbol(5) "pubchem:X" if X is a pubchem id or
                                  name
  --adsorbate-formula COMMA_DELIMITED_STRING
                                  Formula of adsorbate.
  --bonds LITERAL_EVAL            Atom index of adsorbate to bind to the slab. Single
                                  integer for monodentate adsorbates. Comma-separated
                                  integers for bidentate adsorbates.
                                  "Monodentate"/"bidentate" can be specified for CatPlat
                                  to automatically determine the binding atoms.e.g. -b 0
                                  -b 0,1 -b monodentate"
  --connectivity LITERAL_EVAL     Connectivity is the number of surface atoms of
                                  adsorption site that the adsorbate binds to. For a
                                  fcc(111) surface, for example, "1" is the top site,
                                  "2" is the bridge site. Single integer for monodentate
                                  adsorbates. Comma-separated integers for bidentate
                                  adsorbates. e.g. -c 1 -c 1,1
  --avg-coord-num LITERAL_EVAL    Average coordination number of adsorption site that
                                  the adsorbate binds to. Can be an integer e.g. 7, or
                                  comparator e.g. <7. Single values for monodentate
                                  adsorbates. Comma-separated values for bidentate
                                  adsorbates. e.g. -n 7 -n 7,7 -n "<=8", -n "<8,7"
  --site-formula LITERAL_EVAL     Chemical species of the adsorption site i.e. Cu2Zn for
                                  Cu2-Zn hollow site.
  --rotation LITERAL_EVAL         Rotation of adsorbate around the axis of adsorption.
                                  For monodentate adsorbates only.
  --is-symmetric COMMA_DELIMITED_STRING
                                  Whether the adsorbate is symmetric around the
                                  adsorption axis.
  --adsorbate-indices LITERAL_EVAL
                                  Indices of adsorbate.
  --bonding COMMA_DELIMITED_STRING
  --energy-above-minimum STR|FLOAT
                                  Energy above minimum energy structure used for
                                  vibration calculations. (eV)
  --molecule TEXT                 Name of the gas phase molecule.
  --molecule-formula TEXT         Formula of the gas phase molecule.
  --insertion-species TEXT        Chemical symbol of the inserted species.
  --host-size INT|STR...          Supercell size of the host atoms to used for building
                                  the inserted structures.
  --host-x-length STR|FLOAT       x length of the host structure used for building the
                                  inserted structures. (Å)
  --host-y-length STR|FLOAT       y length of the host structure used for building the
                                  inserted structures. (Å)
  --host-z-length STR|FLOAT       z length of the host structure used for building the
                                  inserted structures. (Å)
  --num-occupied-sites STR|INT    Number of occupied sites.
  --inserted-chemsys TEXT         Chemsys of the inserted structure.
  --inserted-formula TEXT         Chemical formula of the inserted structure.
  --singlepoint-chemsys TEXT      Species of the supercell, sorted alphabetically and
                                  separated by dashes.
  --singlepoint-formula TEXT      Formula of the supercell.
  --singlepoint-provenance TEXT   String for the origin of supercell atoms.
  --singlepoint-atoms TEXT        Name of supercell file in user supercell directory.
  --amorphous-supercell-size INT|STR...
                                  Size of amorphous structure in terms of number of unit
                                  cell repeats.
  --heatcool-num-steps STR|INT    Number of steps used in the heat-cool stages of the
                                  amorphous structure generation.
  --equilibration-num-steps STR|INT
                                  Number of steps used in the equilibration stages of
                                  the amorphous structure generation.
  --melting-temperature STR|INT   Melting temperature used in the amorphous structure
                                  generation. (K)
  --starting-temperature STR|INT  Starting temperature used in the amorphous structure
                                  generation. (K)
  --replica-index STR|INT         Replica index for molecular dynamics simulations.
  --md-heating-num-steps STR|INT  Number of steps used in the heating stage.
  --md-equilibration-num-steps STR|INT
                                  Number of steps used in the equilibration stage.
  --md-temperature STR|FLOAT      Target temperature. (K)
  --md-production-num-steps STR|INT
                                  Number of steps used in the production stage.
  --md-trajectory-writing-interval STR|INT
                                  Interval (in number of steps) at which the trajectory
                                  is written.
  --md-early-stopping-criterion TEXT
                                  Name of the early stopping criterion (e.g.
                                  diffusion_coefficient_convergence).
  --md-early-stopping-kwargs TEXT
                                  Keyword arguments for the stopping criterion
                                  constructor.
  --md-early-stopping-check-interval STR|INT
                                  Steps between stopping criterion evaluations.
  --md-production-min-steps STR|INT
                                  Minimum production steps before stopping criterion is
                                  evaluated.
  --ts-replica-index STR|INT      Replica index for molecular dynamics simulations.
  --ts-temperature STR|FLOAT      Target temperature (K).
  --ts-production-num-steps STR|INT
                                  Total MD steps.
  --ts-min-steps STR|INT          Minimum steps before early termination.
  --ts-trajectory-writing-interval STR|INT
                                  Interval (steps) for writing trajectory frames.
  --ts-timestep STR|FLOAT         Integration timestep (fs).
  --ts-integrator TEXT            Integrator: 'langevin' or 'nve'.
  --ts-seed STR|INT               RNG seed.
  --database-path TEXT            Path to database file (if not specified, will use the
                                  global database path from settings)
  --help                          Show this message and exit.
